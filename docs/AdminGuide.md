# Q-Med System Settings & Admin Guide

The Admin Dashboard is the central control room for Q-Med.

## System Settings Tab
- **Consultation Duration (mins):** Sets the global default for how long a typical appointment lasts. This is used to calculate estimated wait times.
- **Max Daily Appointments:** Prevents booking overflow.
- **Emergency Mode:** Toggles emergency mode for hospitals.

## Managing Staff
- **Doctors:** Register new doctors and assign them to departments and hospitals.
- **Hospitals:** Onboard new hospital locations.

## Analytics
View real-time system metrics, patient demographics, and department breakdowns.
